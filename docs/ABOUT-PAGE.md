# About page

The public hash route is `/#/about`. Legacy `/#/account/about` bookmarks redirect. The page covers the marketplace story, mission, vision, audiences, buyer and seller journeys, principles, trust and FAQs. All seven module links use the existing application routes.

The hero reuses the demo reed-mat photograph. Titles and Open Graph metadata update in the browser. Static Pages serves one HTML shell, so crawlers and share scrapers may see the shared metadata. Dedicated canonical URLs, a sitemap for public pages and page-specific preview cards need prerendering or server rendering on production hosting.
