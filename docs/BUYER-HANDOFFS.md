# Buyer handoffs

Home and Search link to the guided buying-options view. Ready-made results pass the item, variant and requested quantity to the PDP. A supported stock-pilot result opens the existing sign-in and request flow with quantity, pickup date, and notes. An offer can open its original Global Atlas entry, or open Connect with buyer context and preferred offer. Connect displays a review step and saves the requirement locally. Open sample quotations from My Requirements.

Live stock continues to depend on the configured pilot, authorised sessions and existing database access rules. Public catalogue, cross-account Connect requests and verified fulfilment require separately authorised production data and policies. See the [Supabase RLS guide](https://supabase.com/docs/guides/database/postgres/row-level-security) for future exposed tables.
