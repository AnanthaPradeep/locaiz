# Buyer intent model

The guided URL uses find=1 with q, qty, city, destination, needed, pickupDate, customNotes, item, sku, budget, currency and uom. Quantities must be positive safe integers within the supported range. Dates use an explicit YYYY-MM-DD calendar value. A selected variant must exist on the selected catalogue item. Country codes come from the sourcing directory. Budget is optional. Do not include private details in shareable search links.

Saving a guided search retains the validated criteria. A reviewed Connect submission stores a browser-local snapshot and keeps existing sourcing identifiers. Existing requirements retain their original records.
