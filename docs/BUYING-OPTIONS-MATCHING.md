# Buying options matching

Ready-made uses the retail catalogue, supported filters and the selected variant. Available demo quantities account for its inventory and the existing cart cap. Delivery date stays unconfirmed. The same quantity is checked against each supplier offer's MOQ and tier, with destination and customisation assessed on that same offer. Production duration is a lower bound, and quoted values retain original currency. Unknown specifications, shipping charges and transit stay unconfirmed.

Pickup offered is not a stock confirmation. Eligible Nagercoil pilot products and variants can use the existing authenticated request. Shop replies and expiry are read in the existing stock workspace. Stock is not reserved and eligibility alone does not indicate a participating shop has stock.
