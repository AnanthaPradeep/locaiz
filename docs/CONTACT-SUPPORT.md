# Contact support

The public Contact page groups buyer, seller, manufacturing, partnership and trust enquiries. Demo validation runs in memory with sample input. The preview makes no request, creates no ticket and stores no personal data.

No authorised support backend, official inbox, phone, address, support hours, social accounts or grievance officer details were supplied. The public organisation configuration leaves these fields unset.

Before enabling real submission, configure an authorised server endpoint with server-side validation, rate limits, bot protection and idempotency. Store tickets with deny-by-default access and restrict support operations to trusted membership records. Service credentials stay server-side. Verify successful ticket creation, failure and retry behaviour, and denial of cross-account and anonymous ticket reads before public activation.
