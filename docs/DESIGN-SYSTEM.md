# Design system

Royal Black (#0A0A0A) and Creamy Light Milk (#FFF6EC) anchor the palette. Warm Ivory, Soft Cream and Milk White provide light surfaces. Carbon Black and Deep Charcoal provide dark surfaces. The component styles use semantic ink, canvas, paper, panel, line and muted tokens.

Space Grotesk and Manrope pair structured editorial headings with readable controls. Product photography was generated for this demonstration. The responsive layout uses an editorial split hero, a compact module index, product grids and a mobile bottom nav. Interactive styling includes keyboard focus and reduced-motion support.

Use the vector wordmark and L/Z monogram as maintained in the brand kit.
