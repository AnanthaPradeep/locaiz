# Marketplace launch checklist

- [ ] Approved and isolated staging and production projects with restricted operator access.
- [ ] Hosted migration, Auth email, RLS and private Storage checks pass.
- [ ] Attachment security and abuse controls reviewed for real participant uploads.
- [ ] Independent buyer, seller and operator staging scenarios pass with evidence.
- [ ] Monitoring, escalation and redaction tested for authentication, RFQs, uploads and failed deployments.
- [ ] Backup and isolated restore drill meets approved recovery objectives.
- [ ] Security findings resolved or explicitly accepted by the launch owner.
- [ ] Production activation approved and live smoke checks recorded.
- [ ] Pilot-participant consent and operating scope approved before onboarding.
