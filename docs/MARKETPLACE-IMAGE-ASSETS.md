# Marketplace ImageGen assets

All 28 files are original ImageGen compositions exported as WebP. Five paired wide and close-up source scenes provide distinct desktop and mobile artwork. Category images come from independently composed cells in themed ImageGen sheets. FFmpeg exports desktop artwork at 960 pixels wide, mobile at 640 and supporting art at 480 with WebP quality 79.

The renderer uses base-aware lazy images and CSS aspect ratios. The listing resolver prefers the listing image before an illustrative fallback. Visuals do not represent real businesses, verified facilities or live stock.
