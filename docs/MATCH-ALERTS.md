# Match alerts

Open **Account → Notifications → Match alerts** to see new matches, unread count and read state. A match links to its product or supplier offer and to the originating saved search. Opening the match marks it as read. Mark each alert separately or mark all match alerts as read. Orders, bookings, requirements and the Stock Notifications link retain their existing flows.

Checks run on app entry, route changes, and when requested in Saved Searches. The website must be open. This release sends in-app alerts only. See [browser-local setup and the demo simulator](SAVED-SEARCHES.md).
