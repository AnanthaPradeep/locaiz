# PLP features

Shop presents twelve results per page from a catalogue of fifty demo products across ten departments. Desktop uses a filter sidebar. The same controls open in a scrollable dialog on smaller screens. Each product has a unique image, card and existing PDP route. Cards reuse the wishlist, Quick View and demo cart. The CNC listing leads to a prefilled manufacturing enquiry.

Repeated URL parameters select multiple values within a facet. Different facets combine conjunctively. Supplier filters must all match one offer. Price filters compare INR retail amounts. Demo data does not show verified-supplier, genuine review, or discount filters without supporting records.
