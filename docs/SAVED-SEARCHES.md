# Saved searches

Use **Save this search** in Shop, Universal Search, or Global Atlas. Enter a name and choose whether to receive in-app alerts. Searches with no results can be saved. At **Account → Saved Searches**, open, edit, pause, resume, or delete a search. Searches are stored in this browser's LOCAIZ demo state.

Reopened searches use hash routes such as `#/shop?category=Crafts&q=lamp&view=list`. The query uses URL encoding and repeated keys for multi-select criteria. The saved view and sort are separate from match criteria. Search always reopens on the first page.

## Try a new match

Save **Alabaster Match Demo Lamp** in Shop and **Demo restock offer** in Global Atlas before publishing samples. Open **Demo match simulator** in Saved Searches, publish the two illustrative entries, then select **Check for new matches**. Open [Notifications](MATCH-ALERTS.md) to see the alerts. Simulator entries persist in this browser and are separate from the default fifty-product catalogue.
